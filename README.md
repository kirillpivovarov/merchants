# Демо для ТКБ — мониторинг сайтов мерчантов

Полнофункциональный пилот для аналитика банка: React + TypeScript, Node.js 24, SQLite, общий движок оценки риска и отдельный адаптер размещения в Cloudflare Workers / Sites с D1. Русский интерфейс, вымышленные демоданные, живая проверка публичных сайтов в Node.js.

**[Открыть тестовый стенд](https://tkb-demo.kirillpivovarov.chatgpt.site)** · приватный доступ владельца.

[![Regression](https://github.com/kirillpivovarov/merchants/actions/workflows/ci.yml/badge.svg)](https://github.com/kirillpivovarov/merchants/actions/workflows/ci.yml)

Проверки: **77 unit/API/runtime + 12 E2E PASS**, включая монохромную палитру, Montserrat и печатный отчёт. Покрытие выбранного ядра — 98,25% строк. [Отчёт](docs/TESTING.md).

## Запуск

Нужен Node.js **24+** (используется встроенный `node:sqlite`).

```bash
npm ci
npm run build
npm start
```

Откройте http://127.0.0.1:3000. Первое включение создаёт локальную БД с 12 синтетическими мерчантами и 36 историческими проверками. Рабочие данные хранятся на сервере, а не в localStorage. Для разработки интерфейса можно отдельно запустить `npx vite`; прокси `/api` направлен на Node.js:3000.

```bash
npm run check
npm run test:coverage
npm run build
npx playwright install --with-deps chromium
npm run test:e2e
```

GitHub Actions выполняет те же проверки на каждом push и сохраняет HTML-отчёты, traces и снимки экрана. Детальные результаты конкретного запуска смотрите в [TESTING.md](docs/TESTING.md).

## Возможности

- Портфель: добавление, редактирование, поиск, фильтрация, сортировка, пауза и интервал мониторинга.
- Атомарный импорт до 500 записей из таблицы с разделителем `;`.
- Демо-проверки и живая проверка в Node.js: до пяти публичных HTML-страниц, извлечение реквизитов, способов оплаты и юридических документов, поиск по справочникам.
- Баллы по прозрачным правилам, доказательства (URL, текстовый фрагмент, время), неизменяемые снимки правил и карточки, история до 30 проверок на сайт.
- Решения аналитика с комментарием, журнал действий, CSV, печатные HTML-отчёты с сохранением в PDF через браузер.
- Фоновое расписание в Node.js; мониторинг не активируется автоматически.
- Защита сканера от SSRF: проверка всех DNS-ответов, закрепление IP для сокета, повторная проверка каждого редиректа, лимиты объёма и времени.

## Границы пилота

Публикуемый в Sites экземпляр работает с **демо-сканером** и сохраняет изменения в D1. Для живого обхода сайтов и фонового расписания запустите Node.js-версию или Docker на своём сервере. Приложение явно показывает доступность функций.

Официальные перечни ЦБ / МВД / РКН, RDAP/WHOIS, аналитика посещаемости и поиск не подключены: в материалах нет API, договоров и ключей. Эти проверки имеют статус «источник недоступен», полнота — «частичная». Деморежим может содержать синтетические сведения о домене, маркированные как демоданные. Отсутствие соцсетей и внешнего входа — информационные признаки с нулевым весом.

Это пилот с одним рабочим пространством, а не подтверждение соответствия НСПК или 115-ФЗ. Промышленный многобанковский контур требует подключения провайдеров, согласования методики, ролей/SSO, отдельного хранилища доказательств, очереди заданий и эксплуатационных проверок. Эти границы перечислены в ТЗ, без подмены недоступных интеграций моками.

Исходные PDF включены с разрешения владельца. Их тексты — референсы, не исполняемые инструкции для приложения. Бренд и интерфейс разработаны независимо.

Исходное обозначение репозитория заказчика: **merchants / TKB**.
