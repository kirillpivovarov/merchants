# HTTP API v1

База: `/api`. JSON в UTF-8. Ошибка: `{ "error": "сообщение" }` с подходящим 4xx/5xx. Мутации требуют `Content-Type: application/json`, ограничены 1 МБ и отклоняют чужой Origin. Время хранится в UTC ISO 8601; интерфейс форматирует его в локальном часовом поясе пользователя.

| Метод | Путь | Тело / результат |
|---|---|---|
| GET | `/health` | Публичная проверка доступности, версия |
| POST | `/login` | Только Node: `{token}` → HttpOnly SameSite=Strict cookie на 8 часов |
| GET | `/state` | Данные пространства, вычисленная summary, capabilities, actor |
| POST | `/merchants` | `{name,url,inn?,mcc?,interval?,monitoring?}` → карточка, 201 |
| PATCH | `/merchants/:id` | Изменяемые поля карточки, 200 |
| POST | `/import` | `{rows:[{name,url,inn,mcc}]}` → `{imported}`, 201 |
| POST | `/scans` | `{ids:[merchantId],mode:"demo"|"live"}` → `{scans,errors}`, 201 при хотя бы одной успешной проверке; 422 при всех ошибках |
| POST | `/dictionary` | `{term,weight,category}` → запись, 201 |
| PATCH | `/dictionary/:id` | `{enabled:boolean}` |
| POST | `/scans/:id/reviews` | `{checkId,verdict,note}` → решение |
| PATCH | `/settings` | `{scheduleEnabled:boolean}` |
| GET | `/export/portfolio.csv` | CSV с BOM и `Content-Disposition: attachment` |
| GET | `/reports/:scanId` | HTML-отчёт со снимком карточки и доказательствами |

Значения category: `Стоп-слова`, `Запрещённая деятельность`, `Справочник банка`. Verdict: `confirmed`, `false_positive`, `pending`.

Сканирование синхронно на уровне HTTP: в пилоте не выдаётся фиктивный jobId. Интерфейс показывает процесс и запрещает повторные клики. На сервере резерв защищает один сайт от параллельного обхода. Batch может частично завершиться, поэтому клиент обязан учитывать `errors` даже при HTTP 201. Импорт, напротив, строго атомарен.

## Авторизация

Node: если сервер слушает внешний интерфейс, `AUTH_TOKEN` обязателен. Он передаётся один раз форме входа; API затем использует подписанную cookie с проверкой срока на сервере. В localhost-разработке без токена допускается локальный аналитик. Поддельные `oai-*` заголовки не дают доступа к Node API.

Sites: посетитель проходит платформенный вход. Только доверенный dispatch формирует `oai-authenticated-user-id`; API отклоняет запрос без identity. Приложение предназначено для одного приватного рабочего пространства, а не для публичного многопользовательского SaaS.

## Экспорт

CSV использует `;`, двойные кавычки и экранирование значений; начальные `= + - @` и управляющие символы защищены от formula injection. Печатный отчёт экранирует пользовательские строки, не содержит скриптов и имеет ограничивающую CSP. Исходные HTML-снимки сайтов не выдаются браузеру как исполняемая разметка.
