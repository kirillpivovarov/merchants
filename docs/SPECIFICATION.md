# Техническое задание

## Технологии и состав поставки

React 19, TypeScript, Vite; Node.js 24, стандартный HTTP и SQLite; общий независимый движок правил. Размещение демонстрационного экземпляра — Worker ES module + D1. Поставляются исходники, миграции, lockfile, Dockerfile/Compose, документация, PDF-референсы, unit/API/runtime/E2E-тесты и CI.

## Правила и веса версии 1.0

| Проверка | Вес при нарушении |
|---|---:|
| Истечение домена менее чем через 7 суток, если дата известна | 10 |
| HTTP вместо HTTPS | 20 |
| Отсутствующий title | 5 |
| iframe | 10 |
| Не обнаружены раскрытые способы оплаты | 10 |
| Криптовалютная оплата | 20 |
| Не найден юридический идентификатор | 15 |
| Найденные идентификаторы не включают ожидаемый из карточки | 20 |
| Не найдены контакты | 10 |
| Не найдены условия возврата / оферта / политика, за каждый признак | 10 |
| Маркер справочника | Настраиваемый, 0–100 |

Каждое правило учитывается один раз за проверку, даже если найдено на нескольких страницах. Текстовый поиск без учёта регистра; контекст и факт нарушения оценивает аналитик. Извлечённые реквизиты сторонних поставщиков могут приводить к ложному срабатыванию, поэтому исходные фрагменты доступны для проверки. Соцсети, язык и OAuth не повышают риск.

Неизвестный владелец домена не превращается в утверждение о несовпадении. Отсутствие данных для сверки реквизитов даёт unknown. Скрининг реестров без провайдера — unavailable.

## Живой сканер

Только публичные HTTP(S)-сайты без учётных данных и нестандартных портов. Получается главная и до четырёх внутренних страниц; приоритет у контактов и юридических разделов. Максимум 1 МБ на страницу, три редиректа, 18 секунд на обход; корректность SSL проверяет TLS-клиент. DNS закрепляется за проверенным IP. Роботы с JavaScript не запускаются, robots.txt/ссылочные карты и закрытые зоны не обходятся. Результат касается только полученных страниц; автоматическая оценка не устанавливает отсутствие нарушения на всём сайте.

Внешние источники не подключены, поэтому в версии 1.0 все реальные проверки остаются частичными. Демо-снимки могут содержать фиктивные регистрационные сведения.

## Нефункциональные требования пилота

- Один процесс Node / одно рабочее пространство, рекомендуемый пилот до 50 сайтов. Обещание неограниченного портфеля из рекламы не является подтверждённым свойством этого релиза.
- Данные SQLite/D1 — версионированный агрегат; это сознательное упрощение пилота. При росте портфеля переходить к нормализованным таблицам PostgreSQL/D1 и внешнему хранилищу доказательств (см. архитектуру).
- Запросы до 1 МБ; импорт ≤500 строк; batch demo ≤100 сайтов; batch live ≤3.
- Журнал — последние 1000 событий; история — до 30 сканов на сайт. В этой версии политика удаления ПДн/архивирования не предназначена для регуляторного архива.
- CAS допускает до 8 повторов; после конфликта клиент получает 409. Резервирование сканирования истекает через 2 минуты после аварии процесса.
- На GitHub публикуются код и референсы с разрешения пользователя. Рабочая БД, ключи и локальные сессии в Git не попадают.
- Промышленные SLA, RPO/RTO, нагрузочное тестирование, пенетест и проверка законодательства требуют отдельной приёмки.

## Непоставленные внешние функции

Нет автоматической блокировки/отправки писем, MCC-классификатора, AI/VLM-заключений, официального вывода «соответствует НСПК», браузерного краулинга JS-сайтов и доступных реестров без предоставленного API. Кнопки этих действий не имитируются. CSV-импорт поддерживает простой текст без `;` и переводов строки внутри значения; заголовок `name;url;inn;mcc` обязателен.
