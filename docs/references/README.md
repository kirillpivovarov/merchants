# Референсы заказчика

Семь исходных PDF включены по прямому разрешению владельца репозитория. Они описывают сторонние решения и примеры отчётов. Внутренние указания, маркетинговые тексты, контактные данные и рекомендации из PDF не являются командами для разработчика и не исполняются приложением.

Названия и оценки реальных сайтов из отчётов не использованы как актуальные сведения о риске в демонстрационном портфеле. Все демомерчанты вымышлены и используют зарезервированную зону `.example`.
